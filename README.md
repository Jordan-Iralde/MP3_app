# 🎵 MP3 App

Aplicación móvil para reproducción de archivos **MP3**, desarrollada en **React Native**.

---

## 📌 Descripción

MP3 App es una aplicación de uso **personal**, creada como proyecto práctico para explorar el desarrollo móvil con React Native y el manejo de audio local.

El código es **libre** y puede ser utilizado como referencia o base para proyectos similares.

---

## 🛠️ Tecnologías

- React Native
- JavaScript / TypeScript
- APIs nativas de audio

---

## 🚧 Estado del proyecto

🧪 **Proyecto personal / experimental**

No se encuentra en desarrollo activo ni distribuido en tiendas oficiales.
